# Live read-only university source validation — 2026-09-25

## Scope and safety boundary

This validation used official university pages and one user-authorized, visible Penn Handshake session. It performed no registration, deregistration, session booking, waitlisting, saving, messaging, applying, uploading, profile editing, or hidden-endpoint access. No account-only employer/session detail, user identity, cookie, browser metadata, screenshot, or private token is stored here.

Current observations are dated `2026-09-25`. Event pages can change. “Visible” means visible in the cited source at access time; it does not imply complete platform coverage.

## Penn public-preview limitation

The official Penn page states that participating employers can be viewed before candidate registration, but session times cannot be reserved until sign-ups open. A direct anonymous fetch of the linked Handshake employer-preview URL was not available to the web reader, and opening it in the already authenticated browser redirected to the registered student view. Therefore this run validates the **official public claim and metadata**, but does not claim an independently anonymous Handshake `PUBLIC_PREVIEW` observation. The safe output remains `PARTIAL`.

## Reproducible adapter finding and fix

Before this validation, `handshake_authenticated_read_only` marked coverage complete even when only event metadata and zero employers had been observed. A failing regression test reproduced `{"visible": 0, "advertised": null, "complete": true}`. The adapter now marks coverage complete only when `employer_list_kind=complete` or the visible count matches a known advertised count.

Eight sanitized fixtures under `career-fair-battle-plan/examples/live-source-fixtures/` replay the source shapes without account data. Each runs through `normalize_source.py`, produces no invented employer leads, and returns incomplete coverage.

## What these sources can and cannot support

Without registering or authenticating, official pages can reliably establish event identity, date, format, audience, advertised scale, and sometimes a public employer list. That is enough for discovery and preliminary filtering, not final booth routing. Exact JD, sponsorship, HC, salary, eligibility, and live session availability require exact-role/employer evidence or a visible authenticated source; missing fields remain `unknown`.

Observed current/future source: HKUST Oct 2026 is upcoming as of access date. Penn, Cornell, Toronto, HKU, and CUHK pages describe already completed 2026 events; they validate source patterns and historical facts, not present availability. Berkeley confirms its current 2026–2027 program but did not expose individual calendar rows in the fetched text.
